第二部分 · 价格：把分散的知识折成一个数

弹性：同一笔税，谁真正付了钱

上一课你让供给和需求在一张十字图里自己「找」出价格。可同一个冲击，结果并不一样：歉收的年份，有时价格涨得吓人、数量几乎没动，有时价格几乎不动、数量大减；同一笔税，有时买家觉得疼，有时卖家觉得疼。差别只在一个量上：价格变了，人能在多大程度上改变数量。这一课把它叫作弹性，并用它回答一个常被答错的问题：一笔税，到底是谁真正付了钱？

被什么逼出同一个冲击——一道税、一次歉收——为什么有时让价格大变、数量不变，有时恰好相反？到底谁真正付了钱？ 本课弹性（elasticity）量的是：价格变一点，数量跟着变多少。同一笔税最后落在谁头上，不取决于法律让谁交，而取决于买卖双方谁更「没得选」，也就是谁的弹性更小。顺带还有一笔账：两边越有得选，税让多少好交易白白消失就越多。 逼出下一课价格不只在分配现有的东西，还在告诉资本和劳动力往哪儿去。那么高利润的地方，为什么好景总是不长？ → 07
出处小注
本课的框架是公共经济学里「税收归宿」（tax incidence）的标准结果：Fullerton 与 Metcalf 2002 年 3 月的《税收归宿》（Tax Incidence，NBER 工作稿 8829，后收入《公共经济学手册》一章）写道，税的负担会通过更高的价格落在消费者身上，通过更低的工资落在工人身上，通过更低的回报落在其他生产要素身上；在只看一个市场的分析里，怎么分摊取决于供给弹性相对于需求弹性的大小。下面模拟器里的基准价 10 元、基准量 100 单位、所有供给弹性，以及「餐厅」预设，都是示意；汽油、香烟预设里的需求弹性取自正文表格里的研究，但供给弹性仍是示意。模拟器输出的是模型的数字，不是任何真实税种的分摊比例。
本课路线
(1) 同一个冲击，两种结果：什么是弹性；(2) 涨价能多收钱吗：收入测试与丰收悖论；(3) 同一笔税，谁真正付了钱：三行推出来；(4) 动手：这笔税谁来扛；(5) 现实里的证据：法律归宿不等于经济归宿；(6) 税的另一笔账：死重损失与公平；(7) 时间会改变弹性；(8) 模型的边界。反直觉的结论：法律上谁交税，无关紧要；谁更「没得选」，谁付得多。

一、同一个冲击，两种结果

先看一个小谜。两个市场同时遇到一次减产，供给都向左移。一个市场卖的是每天都要吃的主食，另一个卖的是随时能换成别家的东西。

主食那边：价格涨得很凶，可大家照买不误，成交量几乎没动，因为人总得吃饭。另一边：价格刚涨一点，买家转头就去买别家的，成交量大减，价格反而涨不上去。同一个冲击，一边是「价格动、数量不动」，另一边是「数量动、价格不动」。上一课末尾的那个问题，答案就在这里。

衡量这个差别的量叫价格弹性（price elasticity）。需求的价格弹性定义为：

需求弹性 εd = 需求量变化的百分比
　　　　　÷ 价格变化的百分比（取绝对值）

需求量和价格反向变动，算出来是负数，大家习惯去掉负号来说。价格涨 10%、需求量降 3%，弹性就是 0.3。弹性小于 1 叫缺乏弹性（inelastic）：价格动得再多，数量也动得很少；大于 1 叫富有弹性（elastic）：价格一动，数量大动；等于 1 叫单位弹性。供给的价格弹性 εs 同理：价格涨 1%，卖家愿意多供应百分之几。它是正数。

弹性的大小，说穿了就是「有多少出路」：

1价格变了。买家看到更贵，卖家看到更有得赚（或更没得赚）。
2问一句：有没有出路？买家：有没有替代品，是不是非买不可，占不占预算大头，有没有时间调整。卖家：有没有闲置产能，能不能转产，扩产要多久。
3出路越多，数量动得越大。几乎没有出路的一方，只能咬牙接受这个价格，数量几乎不动：弹性小。

现实里的弹性长什么样？下表只列本课能核到来源的估计，一律取绝对值。

二、涨价能多收钱吗：收入测试

弹性最直接的用处，是回答卖家的一个老问题：涨价，总收入会升还是降？总收入 R = 价格 P × 数量 Q。价格涨 1%，数量降 ε%，两个变化加起来，收入大约变化 (1 − ε)%：

收入变化 ≈ 价格变化 + 数量变化
　　　　 = (1 − ε) × 价格变化

所以涨价只在需求缺乏弹性（ε < 1）时才多收钱；富有弹性（ε > 1）时，涨价反而少收钱。下面是价格涨 10% 时的算术（弹性 2 是为了对照而设的假设值）：

弹性数量约变化收入约变化
0.3（缺乏弹性）−3%+6.7%（1.10 × 0.97）
1（单位弹性）−10%−1%（几乎不变；价格变动越小越接近 0）
2（富有弹性，假设值）−20%−12%（1.10 × 0.80）

把这个算术倒过来，就是农民的「丰收悖论」。食品的需求通常缺乏弹性（这是教科书的口径）。风调雨顺、所有农户一起多收，供给右移，可买家不会因为东西多了就多吃多少，价格只好大跌，才能把多出来的东西卖掉。价格跌的百分比比数量涨的百分比大，农户的总收入反而下降。教科书拿咖啡举例：咖啡的需求弹性约 0.3，20 世纪 90 年代末越南成为主要产地后供给大增，咖啡价格暴跌，据教科书引用的数据，从 90 年代中期每磅约 2 美元跌到 2001 年不到 0.5 美元。

按 0.3 的弹性算一笔：为了多卖出 3%，价格得降 10%，收入约变成 0.90 × 1.03 = 0.927，少了 7.3%。这是算术，不是某次丰收的统计；真实丰收事件里农户总收入的变化，这里没有可靠数字，不写。还要分清两个层次：对一户农民，自己的田多收一成是好事，因为一户的产量改变不了市场价；对所有农户同时多收一成，却是另一回事。

收入测试替卖家回答「涨价划不划算」。同一套弹性，还能回答一个更尖锐的问题：政府对每件东西加一笔税，价格会怎么动，谁多掏钱？

三、同一笔税，谁真正付了钱

设想政府对某种东西每卖一件征税 t 元。法律要写明谁来交：规定卖家把税交给税务局，或者规定买家交。直觉说：法律说谁交，谁就付。我们把这个直觉放进上一课的供需十字里检验。

加税之后，市场上不再是一个价格，而是两个：买家实际付出的价 Pc，和卖家实际到手的价 Pp。两者之差就是税：Pc − Pp = t。买家和卖家各自对着自己那个价格调整数量，市场只有在两边想成交的量对得上时才会稳定。设无税时价格是 P0、数量是 Q0，买家多付 B = Pc − P0，卖家少收 S = P0 − Pp，B + S = t。

1买家那边：价格涨了 B/P0，需求量按弹性的定义降 εd · B/P0（占 Q0 的比例）。
2卖家那边：价格降了 S/P0，供给量降 εs · S/P0。
3成交量要对得上：两边降得一样多，εd · B = εs · S；再加上 B + S = t。

两个方程解出来：

B = εs / (εd + εs) · t
S = εd / (εd + εs) · t

也就是买家份额 = εs / (εd + εs)，卖家份额 = εd / (εd + εs)。两个份额之比是 εs : εd，也就是和各自的弹性成反比：谁弹性小、谁没得选，谁就扛得多。还有一件事要看清：整个推导里，没有出现「法律上谁交」这几个字。

代入数字（示意）：P0 = 10 元，t = 2 元，εd = 0.5，εs = 1.5。买家份额 1.5 / (0.5 + 1.5) = 75%，买家多付 B = 1.5 元，买价 11.5 元；卖家少收 S = 0.5 元，到手 9.5 元。验算：买家那边价格涨 15%，数量降 0.5 × 15% = 7.5%；卖家那边价格降 5%，数量降 1.5 × 5% = 7.5%。两边对得上，成交量从 100 降到 92.5。

为什么法律上谁交不重要？看两种写法，各自怎样走到同一个终点：

法律写成一开始市场怎样拉回来终点
卖家交卖家想把税加进标价（标价已含税）标价一涨，买家少买；卖家加不满，一部分税只好自己吃下。能加多少，看买家有多少出路买家总共付 Pc，卖家到手 Pp
买家交标价不动，税在收银台另加；卖家想：「那是买家的事」买家嫌「价格加税」太贵，少买；卖不掉的卖家只好降价招徕。降多少，看卖家有多少出路同样的 Pc 和 Pp

税务局只决定谁去递那张支票，价格会自己把钱重新分一遍。

你会看到四件事。第一，默认情形（εd = 0.5，εs = 1.5，t = 2 元）里，法律规定卖家交税，买家却扛了 75%，每单位多付 1.50 元；点「法律上由买家交」，所有 KPI、两个价格、成交量和三角形一个数字也不变，变的只有上面那条横条的颜色。法律上谁交，无关紧要。第二，点「汽油 2001–06 年」：需求弹性取 0.06，供给弹性用示意的 1.00，买家扛 94.3%，成交量只降 1.1%，死重损失 1.13 元；再点「香烟·青少年」（需求弹性 1.43，供给弹性同样是示意的 1.00）：买家只扛 41.2%，卖家反而扛了 58.8%。谁更没得选，谁扛得多。这些比例是模型的输出，不是汽油税或香烟税的真实分摊：供给弹性是示意值；预设还把青少年单独当成一个市场来演示，而一笔真实的香烟税面对的是所有买家，分摊要看全体买家合起来的弹性。第三，死重损失随弹性变大：把两个弹性都拉到 3，死重损失 30.00 元；都拉到 0.1，只有 1.00 元。税额翻倍（默认设置下从 2 元到 4 元），死重损失从 7.50 元变成 30.00 元，翻了四倍。第四，把两个弹性都拉到 3 再慢慢加税，税收先升后降，约在 t = 3.3 元处到顶：再往上加，税基缩得比税额涨得还快。

五、现实里的证据：法律归宿不等于经济归宿

模型说：归宿由弹性决定，和法律上谁交无关。这是一个可以拿证据检验的预测。下面几项研究都在问：法律写在一处，钱最后落在哪里？

研究法律上谁交发现提醒
智利社保私有化，Gruber（1995 年 NBER 工作稿）企业缴工资税所用制造业样本里，平均工资税率六年间从约 30% 降到 5%；结论是这笔税全部由工人以更低工资的形式承担，对就业没有可测量的影响这里只核到工作稿
瑞典削减年轻工人的雇主工资税，Saez、Schoefer 与 Seim（2019，《美国经济评论》）雇主符合条件的年轻工人税后工资没变（对比稍年长、不符合条件的工人），青年就业高约 2–3 个百分点；雇用年轻人多的企业得到更大红利，随后扩张，并给所有员工加薪，被解读为「租金分享」具体年份和削减幅度这里没有核到
美国各州汽油税与柴油税，Marion 与 Muehlegger（2011）各州规定税传递到零售价的程度取决于供应链的约束；在与需求冲击无关的供应约束下，传递率下降摘要没有给出买家与卖家的具体分担比例
美国香烟税，Harding、Leibtag 与 Lovenheim（2012）各州规定跨州能买到低税品，使税的传递程度因地而异；不同收入和教育程度的家庭，负担也不同摘要级信息：没有给出具体分担比例，这里也不引用该文关于传递率高低的结论

智利和瑞典放在一起特别有意思：两个案例里法律上缴税的都是雇主，结果却不同。智利的研究发现税几乎全由工人扛，瑞典的减税却几乎没有传到目标工人的工资上：雇用年轻人多的企业得到了更大的红利，随后扩张，还给所有员工加了薪。两者不矛盾，但说明归宿取决于市场条件，比如工资能不能调整。这并不推翻本课的模型：模型只说，归宿由两边的出路决定，而不是由法律决定；它没有说，出路的大小在所有市场里都一样。

六、税的另一笔账：死重损失与公平

不管这笔税最后由谁扛，还有一笔账不归任何一方：消失的交易。每一单位因为税而没成交的东西，原本都是对买卖双方有利的交易：买家愿付的价高于卖家的成本。这些消失的好处就是死重损失，图里那块红色三角，底是税 t，高是少成交的量 |ΔQ|，面积 ½ · t · |ΔQ|（和第 05 课里的三角是同一个）。把买家那边的数量变化代入 B 的结果：

|ΔQ| = Q0 · [εdεs / (εd + εs)] · t/P0
死重损失 = ½ · t · |ΔQ|
　　　　 = ½ · (Q0/P0) · [εdεs / (εd + εs)] · t²

  • 两边越有得选，损失越大。方括号里的量随两个弹性一起变大。
  • 只要有一边几乎没出路，损失就小。方括号里的量比两个弹性里较小的那个还小；一边完全没出路时它等于 0，税只是把钱从一方搬到另一方，不让任何交易消失。
  • 损失和税额的平方成正比。税额翻倍，损失翻四倍。

效率账的结论因此很直接：同样要收一笔钱，对弹性小的东西收，白白消失的交易更少。这是可以算出来的实证结论。可弹性小的东西，往往是人离不开的东西。如果它们在低收入家庭预算里占的比重更大（这要看具体商品和数据），这笔税压在这些家庭身上的分量就更重，这样的税叫累退税（regressive）。烟草税的研究就发现，不同收入、教育程度的家庭负担不同。所以一边是效率账（能算：红色三角有多大），一边是公平账（要判断：该不该让谁多掏）。前者是实证问题，后者是规范问题，模型只能替你算前一个。怎样权衡，可以接着读《政治的逻辑》第 08 课《平等与正义：蛋糕该怎么分？》。

七、时间会改变弹性

前面一直把弹性当成一个固定的数，其实它会随时间变。汽油涨价的第二天，你照样得开车上班；一年后，你可能换了省油的车，或者搬到离公司更近的地方；再过十年，整座城市的布局都在变。给的时间越长，买家的出路往往越多，需求弹性往往越大。供给也一样：卖家短期内没法扩产，几年后可以建新厂、转产。

两边的弹性都随时间变，所以归宿怎么变，要看哪一边变得更快。如果两个弹性同时放大同样的倍数，分摊比例不变，但死重损失按同样的倍数放大。你可以在模拟器里把两个滑块一起往上拉试试。

不过「时间一长，弹性就大得多」只是倾向，不是定律。前面表里的两组汽油数字都是短期估计，比较的是两个高油价时期，不能当成「短期对长期」。汇总研究认为能源品的需求在短期和长期都缺乏弹性；香烟的汇总里，短期研究的平均弹性是 0.40，长期研究是 0.44，几乎一样（Gallet 与 List，转引自《Tobacco in Australia》）。弹性随时间变大多少，要看替代品能不能真的出现，得用具体市场的数据说话。

八、模型的边界

模型的边界
这个模型是一个市场、两条直线、一笔小税。①只看一个市场，没算税怎样改变别的市场，也没算政府拿这笔钱去做什么。②需求和供给都画成直线，弹性只在基准点上取值；税一重，真实曲线的弹性会跟着价格变，模型的数字就只剩参考价值（比如把两个弹性拉到 3、税额拉到 5 元，模型会算出死重损失超过税收，这时直线近似已经不可信）。③假设竞争、人人守法：垄断者的定价逻辑不同（第 11 课《垄断与市场力量：当竞争者进不来》），对税的反应也不一样，逃税、避税、跨州购买都会改写结果，美国香烟税的研究就发现跨州能买到低税品，税的传递程度因此因地而异。④弹性是统计估计，口径不同数字就不同：汽油两个时期、香烟两类人群，都差好几倍。⑤智利和瑞典说明，归宿还取决于工资能不能调、企业有没有分享的空间，这超出了两条弹性线能讲的。⑥为什么政府收这种税、不收那种税，是政治的问题，见《政体的逻辑》第 04 课《钱从哪来：税收逼出谈判，资源养出独裁》。谁在多大程度上扛税，要靠具体市场的数据判断，公式一代并不能替代；预设里的供给弹性全是示意，模拟器里的分摊比例不是任何真实税种的分摊比例。第 23 课《经济的逻辑（收官）：读懂任何一条经济新闻的六个问题》的新闻体检仪，会重用这一课的线性模型。
回到主线
没有人能安排一切，也没有人知道一切，立法者也一样：写得出谁交税，却安排不了税最后落在谁头上。价格是信号（第 04 课），一笔税把一个信号劈成了两个，买家看到的价和卖家到手的价，各自按自己看到的数字调整数量。引擎里的第三个问法「谁承担后果（激励）」在这里有了可以计算的答案：后果落在谁头上，不由法律上谁写支票决定，而由谁更没有出路决定。第一个问法「代价是什么」也在场：每一笔因为税而消失的交易，都是白白放弃的好处。可价格这个信号还没讲完：它不只在分配现有的东西，也在告诉资本和劳动力往哪儿去。

常见误解

  • 误解：法律规定谁交税，谁就是真正付税的人。 （澄清：法律只决定谁去写支票。真正多掏、少收的钱，由两边各自有多少出路决定：模型里，法律上由买家交还是由卖家交，解出来的价格和成交量一模一样；智利、瑞典的研究也显示，雇主缴的工资税落在谁头上，要看市场条件。）
  • 误解：对商家征税，商家都能加到价格里，所以最后全是顾客付。 （澄清：能加多少，看顾客有多少出路。顾客容易换走（弹性大）时，商家加不动，只好自己吃下大部分；模拟器的「香烟·青少年」预设里，卖家扛的比买家还多，不过那是模型输出，供给弹性是示意。）
  • 误解：弹性就是需求曲线陡不陡。 （澄清：斜率跟着单位走，换个单位就变；弹性是「百分比对百分比」，没有单位。而且同一条直线上不同位置的弹性也不同，所以说弹性要说清是在哪个价格附近。）
  • 误解：涨价总能多收钱。 （澄清：只有需求缺乏弹性才行。富有弹性的东西涨价，数量掉得更快，总收入反而下降；反过来，丰收可能让全体农户的总收入下降。）
  • 误解：对弹性小的东西征税最好，因为白白损失最小，所以应该多对必需品征税。 （澄清：这只回答了效率那一半：红色三角确实更小。税压在谁身上、该不该让谁多掏，是公平的问题，要靠价值判断，模型替你算不了。）
  • 误解：一种东西有一个固定的弹性。 （澄清：同一种东西，不同时期、不同人群、不同期限，估计值常差好几倍：美国汽油 2001–2006 年的短期估计比 1975–1980 年小得多，香烟的成年人和青少年相差好几倍。）
一句话带走
同一笔税，法律只决定谁来写支票，价格会自己把钱重新分一遍：谁更「没得选」（弹性更小），谁就扛得更多；而两边越有得选，这笔税让多少好交易白白消失就越多。
下一步
价格不只在分配现有的东西，还在告诉资本和劳动力往哪儿去。那么高利润的地方，为什么好景总是不长？ → 第 07 课《竞争与利润：好生意为什么会被抄》会回答：利润是一个信号，它把别人的钱和人手吸引过来，直到好处被抄平；我们还会用「猪周期」看一件事：如果大家跟着昨天的价格做决定，这个信号反而会让市场来回摆动。
