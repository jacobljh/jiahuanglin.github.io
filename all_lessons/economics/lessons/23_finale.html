经济的逻辑（收官）：读懂任何一条经济新闻的六个问题

上一课我们给「量得到的东西」找了一把尺子（GDP），又看了蛋糕是怎么分的。可真正碰到你的，是每天的新闻：「某地限租金」「最低工资要涨」「汽油加税」。这些头条背后是同一套问题。把所有的链条拼回去：读到任何一条经济新闻，先问哪几个问题？这一课不再引入新机制，只做三件事：把 23 课串成一根绳，提炼成六个问题，再用一台「新闻体检仪」练一练。

被什么逼出把所有的链条拼回去：读到任何一条经济新闻，先问哪几个问题？ 本课不再引入新机制：把 00–22 课串成一根绳，提炼成六个问题（谁放弃了什么、价格里装了什么又漏了什么、谁付钱谁受益、谁承担后果、谁来执行承诺、这是水平还是速度），再用一台体检仪把一条政策头条拆开，看每个问题的答案怎样随弹性、力度和时间长短而变。 逼出下一课经济学不会替你预测明天，但会告诉你该问什么、该怀疑什么、谁在为谁付账。
出处小注
本课引用的经济学家调查来自芝加哥大学 IGM 论坛（Clark Center Forum）：一个约 38–46 人的美国经济学教授小组，不等于「全体经济学家」，票数按成员计、没有按置信度加权。公众与专家的对比来自保拉·萨皮恩扎（Paola Sapienza）与路易吉·津加莱斯（Luigi Zingales）2013 年的论文《经济学专家与普通美国人》（Economic Experts versus Average Americans，《美国经济评论》103(3): 636–42）。体检仪里的一切数字——基准价 100、基准量 100、弹性、力度、「长期」的 2.5 倍、关税里 40% 的进口占比——都是示意，是模型输出，不是任何真实城市或国家的统计。
本课路线
(1) 一根绳子：00 到 22 的问题与答案；(2) 六个问题，各自背后是哪几课；(3) 动手：新闻体检仪；(4) 三条通用头条，拿来练；(5) 经济学不会做什么；(6) 专家一致的地方，公众为什么不买账；(7) 接下来去哪。反直觉的是：同一条政策，力度翻倍，被白白浪费的好处（死重）不是翻倍，而是变成四倍；时间拉长，又再放大一轮。

一、一根绳子：从早餐到 GDP

这门课不是按话题排的百科，而是一条链：每一课都被上一课没答完的问题逼出来。下面把它们一次摆出来。每一行是一课：它回答的问题 → 它给的答案 → 它逼出的新问题。读的时候留意一件事：每一课的「答案」，都在下一行变成了「问题」的一部分。

00 导览问：没人会造整支铅笔，它为什么还准时出现？ → 答：价格、规则、激励拧成的协调，不靠命令和习俗。 → 逼出：一切从「想要的比能得到的多」开始，代价怎么算？
01 稀缺与取舍问：代价怎么算？ → 答：代价是放弃的最好选择（机会成本），不是价格牌；多做一点，代价越来越高。 → 逼出：一件事该做到多少才停？
02 边际问：该做到多少才停？ → 答：做到边际收益等于边际成本；沉没成本和固定成本不改最优点。 → 逼出：放弃的东西因人而异，样样都强也该交换吗？
03 比较优势问：样样都强，还要交换吗？ → 答：要。看谁放弃得少；价格决定怎么分，比较优势决定蛋糕多大。 → 逼出：几十亿人、数不清的东西，谁来告诉每个人做什么？
04 价格是信号问：谁来告诉每个人做什么、换多少？ → 答：价格：把分散的知识压成一个数，同时传信息、给激励、做配给。 → 逼出：没人下命令，价格怎么被「找到」？
05 供给与需求问：价格怎么被找到？ → 答：需求来自边际价值，供给来自边际成本，交点处没人想改；管制造出短缺、过剩和死重。 → 逼出：同一个冲击，到底谁真正付了钱？
06 弹性问：同一笔税，谁真正付了钱？ → 答：法律决定谁写支票，弹性决定谁掏钱；两边越有得选，死重越大。 → 逼出：高利润的地方，为什么好景不长？
07 竞争与利润问：好生意为什么会被抄？ → 答：利润是信号，引来进入者直到被抄平；进入有滞后就有猪周期，有壁垒就有租金。 → 逼出：竞争只在价格装着全部成本时才管用，没算进去的账呢？
08 外部性与产权问：没算进价格的账怎么办？ → 答：私人成本不等于社会成本：庇古税补进价格，或产权清晰时当事人自己谈拢。 → 逼出：挡不住不付钱的人时，谁出钱？
09 公共品与公地问：挡不住人的东西谁出钱？ → 答：搭便车让价格长不出来；规则、惩罚、声誉与共同体能维持合作。 → 逼出：能定价了，买卖双方知道的还是不一样呢？
10 信息不对称问：你比我更清楚货的好坏时，价格会怎样？ → 答：买家按平均出价，好货先退出，没人撒谎市场也会塌；解药是信号、筛选、第三方。 → 逼出：竞争者进不来时，价格在对谁说谎？
11 垄断与市场力量问：竞争者进不来，价格对谁说谎？ → 答：卖家少产高卖，加价随竞争者增多而缩小；大不等于坏。 → 逼出：补丁要靠人执行，人会照设计行动吗？
12 激励问：人会照设计者想的行动吗？ → 答：人对谁承担后果作出反应；奖励量得到的，会挤掉量不到的。 → 逼出：激励总被钻空子，能否先定好想要的结果，再倒推规则？
13 机制设计问：能否倒推规则，让人说真话？ → 答：改规则不改人：第二价格拍卖里，报真实估值就是最优。 → 逼出：价格和合同也有成本，为什么有的事交给公司下命令？
14 公司问：为什么有的事交给市场，有的交给公司？ → 答：市场有交易成本，尤其是被敲竹杠的风险；成本高就用命令，但命令也有成本，公司因此有边界。 → 逼出：产权谁保护、合同谁执行，这圈规则从哪来？
15 制度问：规则的规则从哪来？ → 答：制度是人定的约束，执行力有价格：执行越弱，借贷越贵，值得做的事越少；规则从哪来，经济学家至今没有定论。 → 逼出：最普遍的许诺是钱，钱是什么？
16 货币问：钱是什么？ → 答：解决「双重巧合」的记账技术：交换媒介、计价单位、价值储藏，全靠人人接受。 → 逼出：银行把同一块钱借给别人，为什么既有用又脆弱？
17 银行与信用问：为什么既有用又脆弱？ → 答：贷款创造存款，短借长贷；挤兑能自我实现；存款保险与最后贷款人压住挤兑，却添道德风险。 → 逼出：购买力创造多了，物价怎样？谁决定数量？
18 通胀与央行问：钱多了，价格为什么跟着动？ → 答：先分清水平与速度；长期物价跟着没有产出匹配的钱走；压通胀的代价取决于预期与可信度。 → 逼出：通胀压得下去，繁荣为什么还是自己种下衰退？
19 债务与周期问：繁荣如何种下衰退？ → 答：稳定催生乐观，乐观推高杠杆，杠杆让借款人变脆弱（明斯基）；刺激的力度有争议。 → 逼出：账跨过国境会怎样？
20 贸易与汇率问：账跨过国境会怎样？ → 答：比较优势走出国境，整体有益、分配不均；关税的账是两个三角形；经常账户 = 储蓄 − 投资。 → 逼出：长期里为什么有的国家富了十倍？
21 增长问：富国为什么富？ → 答：资本积累有边际报酬递减，长期增长来自思想与技术；追赶取决于各国自己的稳态，模型回答不了为什么有的国家追得上。 → 逼出：蛋糕做大了，拿什么量、怎么分？
22 度量与分配问：GDP 量到了什么、漏掉了什么，不平等从哪来？ → 答：GDP 不是福利；基尼系数随口径而变；效率与公平的取舍是规范问题。 → 逼出：把链条拼回去，读新闻先问哪些问题？

二、六个问题，和它们各自背后的课

把这根绳子折叠起来，不同的新闻只是在反复问同样六个问题。它们是总引擎「代价、信号、激励」三问的展开：① 对应代价，② ③ 对应信号，④ ⑤ 对应激励，⑥ 是给所有答案加上时间。

问题它在盯什么靠哪几课
① 谁放弃了什么？价格牌之外那个「被放弃的最好的替代」；决定发生在边际上；交换有好处，是因为各人放弃的不一样01、02、03
② 价格里装了什么，漏了什么？价格说真话有四个前提，破哪个就在哪里说谎：外部性、公共品、信息不对称、市场力量08、09、10、11
③ 谁真正付了钱、谁真正受益？法律上谁交无关紧要，弹性决定谁扛；短期与长期不同；好景会被抄平05、06、07
④ 谁承担后果，人会怎么反应？补丁要靠人执行；奖励量得到的会挤掉量不到的；规则可以倒推；市场与命令各有边界12、13、14
⑤ 谁来执行承诺，承诺可信吗？产权、合同、货币、银行、债务：都是对未来的承诺，靠执行力撑着15、16、17、19
⑥ 这是水平还是速度，是一次还是复利？价格水平与通胀率；存量与流量；增长的复利；GDP 量什么18、21、22

剩下几课的位置：00 是引擎本身；04 是 ② 的地基；20 把 ① 和 ③ 带出国境。下面这台体检仪，让六个问题对着一个具体的政策，各吐出一行答案。

三、动手：新闻体检仪

体检仪是第 06 课《弹性：同一笔税，谁真正付了钱》那个线性模型的升级版：一个市场，基准价 = 基准量 = 100，需求和供给都是过基准点的直线，斜率由弹性决定。五个按钮对应五种常见的政策头条，模型里各自是一道「楔子」：

房租上限把价格锁在 100×(1−力度)，最低工资锁在 100×(1+力度)：一个在均衡价之下，一个在均衡价之上，所以一定生效，成交量由「短边」（供给和需求里较小的那个）决定。税 / 补贴让买方付的与卖方得的相差 100×力度。进口关税是小国版本：世界价固定为 100，国内价 = 100 + 关税，进口占本国消费的 40%（示意）；关税高到进口归零，国内价就封顶在自给自足的价，不再上涨。

滑块是短期弹性；点「长期」，两个弹性一起乘 2.5（示意：时间一长，买卖双方都有了更多出路）。配给一律按最理想的算（愿付最高的人先买到，成本最低的人先卖出），所以屏幕上的死重只是下限。右边四根柱子是买方、卖方、政府的剩余变化和死重，前三项相加恰好等于死重的相反数。下面的「六问」不是写死的文字，而是按当前读数现算出来的。

新闻体检仪：同一个市场，五种政策，六个问题（示意）
先看默认的「房租上限」：把「力度」拖到 10%，再拖到 40%，盯住死重；再点「长期」，看第 ⑥ 行的倍数。然后依次点另外四个政策：同样的滑块，同样的六个问题，答案各不相同。三个预设是后面三条头条的出发点。

你会看到：默认的房租上限把租金压低 20%，可租的房子从 100 掉到 90，另有 20 单位想租却租不到。在「最理想的配给」这个最乐观的假设下，租客整体仍多得 1,700，房东亏 1,900，差出来的 200 就是死重；可第 ② 行补了一句：房子若是随机分、不是给愿付最高的人，租客整体变成 −100。把力度拖到 10%，死重从 200 掉到 50，不是一半而是四分之一；拖到 40%，变成 800，是四倍。点「长期」，缺口从 20 变成 50，死重从 200 变成 500，都是 2.5 倍，而租金一次性降 20% 这件事没变。道理很短：死重 = ½ × 楔子 × 被挡掉的量，两个量都和力度成正比，所以死重和力度的平方成正比；弹性乘 2.5，被挡掉的量跟着乘 2.5。换成征税或补贴，平方律依旧成立。

四、三条通用头条，拿来练

一条头条通常只给一个动作：「某地给房租设上限」「某国提高最低工资」「政府对汽油加税」。体检仪把动作翻成市场里的一道楔子，再让你一问一问地读。用法四步：

1翻成工具。它是价格上限、价格下限、税、补贴，还是关税？
2填三个数。买卖双方的回旋余地（弹性）、政策的猛烈程度（力度）、看一两年还是更久（短期或长期）。
3读六问。先看 ③（谁付钱）和 ⑥（长期会怎样），再看 ② 和 ⑤。
4回到现实。弹性是你填的；真实头条的答案取决于真实的弹性和执行，要去找数据。

头条 A：「某地宣布给房租设上限，称要让年轻人租得起。」点「租金上限·长期」。读数（示意）：租金一次性降 20%，可租的房子从 100 掉到 85，缺口 35（短期只有 14），死重 263（短期 105）。最理想的配给下，租客整体 +1,588，房东 −1,850；随机分配则租客整体只剩 +100。③ 告诉你它在帮谁——租到房的人——也告诉你谁在出钱：房东，以及排不上队的人。体检仪答不了的：房东会不会改作他用、质量会不会下降，那是第 05 课《供给与需求：价格是怎么被「找到」的》讲价格上限时要看的事。

头条 B：「某国宣布上调最低工资，称要让低薪者多拿钱。」点「最低工资·弹性小」。读数（示意）：工资一次性升 15%，就业从 100 降到 97，有 10.5 单位想干却没活；工人整体 +1,446，雇主 −1,477，死重 32。现在只拖一个滑块——把需求弹性 εd 从 0.20 拖到 2.00：就业降到 70，工人整体只剩 +150，死重涨到 1,125。同一个工资下限，在这个模型里，结论很大程度上取决于雇主对工资有多敏感。真实的最低工资证据确有分歧（见下面第五节 2013 年的小组调查）；体检仪又假设劳动力市场是竞争的，那只是简化，真实的结论要看真实的数据。

头条 C：「政府宣布对汽油加税。」点「汽油税·短期 vs 长期」。读数（示意）：买家付的涨 16.7%，卖家到手的降 3.3%，买家承担 83%，卖家 17%——这和法律上谁交无关；成交量降 1.7%，死重 17，政府多收 1,967。再点「长期」：成交量降 4.2%，死重 42，是短期的 2.5 倍，但买家承担的比例仍是 83%：时间改变的是被挡掉的交易，不是谁付钱。② 和 ④ 体检仪答不了：这税是不是在补一笔漏算的账（第 08 课《外部性与产权：价格没算进去的那笔账》），收上来的钱又怎么用。

五、经济学不会做什么

它不替你预测明天。体检仪给的是「如果……那么……」：如果弹性是这样、上限定在八折，那么缺口是这样。真实头条里，弹性多少、会不会被执行、别人怎么反应，都是未知数。模型是地图，不是天气预报。

它不替你站队。体检仪能算出「租客整体 +1,588、房东 −1,850」，算不出「这个交换值不值」：那取决于你怎么看公平，是规范判断，不是实证判断。见《政治的逻辑》第 08 课《平等与正义：蛋糕该怎么分？》。经济学能做的，是把代价摆清楚。

三种读法。第一，有些问题几乎一边倒：2018 年那次，作答的 40 人里没有一个同意「福利会改善」。第二，有些问题真有分歧：2013 年的最低工资，同意、反对、不确定各占一块。第三，分歧有结构：2024 年那次，小组在「能不能增加钢铁业就业」上分成三块（对应 ③ 谁受益），在「总账」上却多数不看好（31 人反对，2 人同意，对应体检仪里的净账）。注意租金那条问的是对可负担租房数量与质量的影响，不是对租客保护的全部评价。

六、专家一致的地方，公众为什么不买账

萨皮恩扎与津加莱斯（2013）把经济学专家的回答与具有全国代表性的美国人口样本的回答对比，两组答案相差 35 个百分点；意识形态和个人特征只能解释差距的一部分，而且差距在经济学家最一致、研究文献最多的问题上最大。告诉受访者专家怎么想，几乎不改变受访者的答案；论文的观察是，普通人似乎怀疑专家答案背后没有明说的假设。这不是说公众「不懂」：专家的答案永远带着一串「在这些假设下」，每课的「模型的边界」做的正是把它们说出口。

模型的边界
体检仪是一张极简的地图。第一，曲线是过基准点的直线，只在小范围内可信；力度大、弹性大时成交量会被推到 0，那是线性模型的人造痕迹，别当真。第二，这个市场里没有外部性、公共品、信息不对称和垄断（第 08–11 课），所以每道楔子都只有扭曲；真漏了账时，符号可能翻过来。第三，配给按总剩余最大的方式算，现实的分法在总剩余上不会比它更好；一块钱对谁都一样，没有分配权重（第 22 课）。第四，政府的钱从哪来、花到哪去没建模；关税只算小国，没有大国的议价与报复（第 20 课）；政策被百分之百执行。第五，它只比较两个静态均衡，没有调整过程；所有数字，包括「长期 ×2.5」，都是示意。它能帮你问出问题，不能替你回答。
回到主线
没有人能安排一切，也没有人知道一切。经济，就是无数各怀己见的人，在稀缺之下，靠价格和规则彼此配合。所以每一个经济问题，最后都落在三个问法上：代价是什么（取舍），信息在谁手里、怎么传（信号），谁承担后果（激励）。翻成新闻里的话，就是：谁放弃了什么，价格告诉了谁什么，谁来承担后果、谁来执行承诺。六个问题只是把这三问摊开。

常见误解

  • 误解：体检仪算出死重大于 0，就说明这条政策不该做。 （澄清：死重只是账本上的一栏。政策可能在补一笔漏算的账，或在追求公平，那些体检仪里都没有。经济学告诉你代价，不替你决定值不值。）
  • 误解：政策力度翻一倍，代价也翻一倍。 （澄清：在这个模型里，死重和力度的平方成正比，翻倍是四倍；时间拉长，被挡掉的交易还会再多。）
  • 误解：IGM 小组的票数，就是「经济学界的共识」。 （澄清：那是一个约 38–46 人的美国经济学教授小组，按成员计票；有的调查一边倒，有的同意、反对、不确定各占一块。）
  • 误解：公众不信专家，只是因为没学过经济学。 （澄清：论文发现，告诉受访者专家怎么想，几乎不改变受访者的答案；普通人似乎怀疑专家答案背后没有明说的假设。）
  • 误解：六个问题答完，就能得出结论。 （澄清：它们是追问的方向，不是计算器。有的答案要靠数据（弹性多少），有的要靠价值判断（谁更该被照顾）。）
一句话带走
读任何一条经济新闻，先问六件事：谁放弃了什么，价格里装了什么又漏了什么，谁真正付了钱，谁承担后果，谁来执行承诺，这是水平还是速度。经济学不会替你预测明天，但会告诉你该问什么、该怀疑什么、谁在为谁付账。
