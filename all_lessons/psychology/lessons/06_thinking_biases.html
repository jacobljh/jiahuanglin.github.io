思维与判断：捷径是缺陷，还是算力有限下的最优解

知觉在补全、注意在筛选、记忆在重建，处处都在拿旧经验换省力；判断和决定也一样。这一课回答这个系列的核心一问：这些「捷径」，是缺陷，还是算力有限时的最优解？答案不是二选一，而是一个可以量的条件。

被什么逼出知觉在补全、注意在筛选、记忆在重建，处处都在拿旧经验换省力；判断和决定也是这样——这些「捷径」到底是缺陷，还是在算力有限时的最优解？ 本课「错」不是一个东西：有的偏误大而稳（明说的参照数、问法的框架），有的被夸大或没站住（随手的数字、行为启动、「没有手感」）。而「走捷径」本身是缺陷还是够用，要看环境和数据量；这是一条可以推出来、也可以拨出来的规律。押注问的，是真实数据上的一场比赛：简单规则对认真算的统计。 逼出下一课捷径在算力有限时可以「够用」；可有一类错误并不出在捷径上，而出在「运气」上：任何一次测量都混着运气，极端的结果下一次会自己往回走，而大脑偏偏会为这种回走编出一个因果故事。这个故事什么时候是错觉？ → 07

Czerlinski 等人（1999）拿 20 套真实数据（比如芝加哥哪所中学的辍学率更高）做了一次比赛：一边是「择优」——把线索按可靠程度从高到低排好，从最可靠的看起，第一个能分出高下的线索就定案，其余不看，平均只看约 2.4 个线索；另一边是多元回归——用上全部平均约 7.7 个线索，给每个线索算出最优权重。比的是谁在没见过的新案例上猜得更准。结果是？

择优略准：新案例上平均 71% 对 68%（数字出自 Todd 与 Gigerenzer 2000 对这项研究的概括表）。在拟合已知数据时，回归反而更好（77% 对 75%）——方向在新案例上翻了过来，这是过拟合的签名：模型把已知数据里的偶然也学了进去，换到没见过的案例就不灵了。 B

但别记成「简单碾压统计」：后来对 83 个德国城市人口数据的重算里，择优和回归只差 0.2 个百分点（71.0 对 70.8），是平手。站得住的是更窄的说法：线索少、样本少的时候，简单规则可以不输。为什么，第三节推出来，第四节你自己拨。

一、先把「错」分清楚

要问捷径是不是缺陷，先要问：和什么比？Simon（1955，1956）的两篇论文是有限理性的奠基之作。后来的「剪刀」比喻是说：行为是被两片刀刃剪出来的，一片是任务环境的结构，一片是行动者的计算能力，只看一片解释不了行为（能查到的最早说法在 Newell 与 Simon 1972 的书里，Simon 1990 重述）。其中的满意化（satisficing）是：一个一个看备选项，遇到第一个达到期望水平的就停，而不是在所有备选项里求最大；Artinger 等人把这个概念的出处定在 Simon 1955。

满意化到底好不好？Artinger、Gigerenzer 与 Jacobs（2022）的综述给了一个按条件分开的裁决：在风险下（选项和概率都已知），满意化通常不如最优化；在不确定下，满意化的规则往往是从经验里得来的，可以非常有效，论文还给出了它成立的条件。这一句，就是这一课的论点：「够用」在一个条件全摆明的问题里输，在未来不确定、数据又少的问题里可以赢。

另一边是 Tversky 与 Kahneman（1974）的综述：代表性、可得性、锚定与调整，三种启发式（省力的经验规则），各带着一串偏误；它自己的概括是，这些启发式很有用，但有时会导致严重而系统的错误。顺便注意一点：这篇综述里的大多数演示只报告中位数或百分比，没有给人数、标准差或检验统计量，所以那些数是论文自己的陈述，不是独立测量。

「偏离标准答案」也不等于「缺陷」。Stanovich 与 West（2000）列了读这个差距的四种办法：执行失误、算力有限、实验者用错了规范、被试对题目的理解不同。从个体差异的数据看，两位作者的结论是：执行失误只是次要因素；算力有限能解释好几类题上的非规范答案（尤其是需要脱离情境思考的）；而协方差的模式可以提示「规范用错了」或「有一种合理的另一种理解」。所以，下面每一个偏误，都要单独称。

二、几个经典的偏误，今天各是什么成色

锚定：同一个名字，三个等级。1974 年的「幸运轮」：当着参与者的面转出一个 0 到 100 的数，请参与者先说联合国里非洲国家的占比比这个数高还是低，再估一个数。收到 10 的一组，中位数是 25；收到 65 的一组，是 45（斜率约 0.36，由这两个数算出）；论文还说，答对有奖并没有减小这个效应；人数和离散程度没有报告。这个原始数字，没有找到对原程序的独立重复；最接近的证据（见下一段）指向更小的效应。 C 能站稳的是另一版——明说的比较锚（先说高还是低，再估计）：Many Labs 1 在 36 个样本里重做了四道这样的题（每题 N 约 5,300–5,600），效应量 d 是 2.43（每天出生的婴儿数）、2.00（珠峰高度）、1.88（芝加哥人口）、1.18（旧金山到纽约的距离），原始研究是 0.93，每个样本里都显著；Schley 与 Weingarten（2026）合并了 2,601 个效应量，Hedges 的 g 的 95% 区间是 [0.765, 0.884]，「即使考虑了大量的发表偏倚，仍然很大」。 A （提醒：Kvarven 等人 2020 比较 15 个元分析和 15 个匹配的预先登记多实验室重复，发现元分析的效应平均接近三倍大，所以元分析的数字只看方向和量级。）

而「无关的数字也能拉着你」（随手一个数、社保号末两位、产品型号），就弱得多。Ariely 等人（2003）：55 名 MBA 学生先写下社保号的末两位，再说愿不愿意出这么多美元买各种东西，最后写下自己愿意出的价；社保号数字最高的五分之一，为一个无线键盘出的价是 55.64 美元，最低的五分之一是 16.09 美元。后来的检验弱得多：Fudenberg 等人（2012）用常见商品重做 Ariely 等人的操作，只找到「很弱」的锚定，二元彩票上一点也没有；Brewer 与 Chapman（2002）的三个实验（N = 881、205、117）里，这类随手数字的效应也很弱，只出现在 Wilson 等人（1996）那套具体操作里，换个排法、换几个数就没了。Critcher 与 Gilovich（2008）的手机型号「P97」对「P17」，d = 0.30；Many Labs 2 在 59 个样本里重做这一题，合并 d = 0.04 [−0.01, 0.09]，只有 5.08% 的样本显著为正。Shanks 等人（2020）的三项研究里，随手的锚没有显著效应，明说的锚稳稳地在。三位作者的结论是：锚定限于需要明确思考那个锚的情形。 D

热手：一个统计量的偏差，能让一个「谬误」翻案。「手感」（热手）是说投中之后更容易再投中，连续命中比随机该有的更多。Gilovich、Vallone 与 Tversky（1985，下称 GVT）分析了篮球队的记录：76 人队 1980—81 赛季的投篮（9 名球员、48 个主场）、凯尔特人队的罚球（9 名球员），并让 26 名康奈尔球员各投 100 次（距离定在约 50% 命中率）。三位作者没有发现超出随机的连续命中，结论是「相信有手感」是对随机序列的认知错觉。Miller 与 Sanjurjo（2018）指出这里藏着一个统计量的偏差。拿三次公平的抛硬币，一共 8 种序列。看「前面一次是正面的那些抛」里，正面占多大比例：

HHT21/2 = 0.5
HTH10/1 = 0

对有定义的 6 种序列取平均：(1 + 0.5 + 0 + 0 + 1 + 0) / 6 = 5/12 ≈ 41.7%，而硬币明明是公平的。在有限序列里，「正面之后的正面比例」的期望，本来就低于一半；所以一个真正没有手感的投手，估计出来的「连中之后与连失之后的命中率之差」是负的。按 Miller 与 Sanjurjo 的报告，GVT 受控实验里测得的差是约 +3 到 +4 个百分点，没有手感的投手预期的差约为 −8，校正偏差后，差约为 +12 到 +13 个百分点（p < .01，标准误约 4.7）。之后的证据：Green 与 Zwiebel（2018）的大联盟棒球面板数据，在 10 项统计指标上都有很强的手感证据，「热」相当于二分之一到一个标准差的球员能力；Lantis 与 Nesson（2024）的 NBA 三分球大赛 1986—2019 年数据发现，手感存在，但只存在于同一位置的投篮；Ritzwoller 与 Romano（2022）则提醒，这类随机性检验需要大得多的数据才能给出有信息的结论。所以：「没有手感，相信手感是认知谬误」这一说法是 D D；「篮球里存在很大的手感」，大小和普遍性仍有争议（防守、位置、功效），是 C C。经统计修正之后，一个经典的结论一头被推翻，另一头还没有定论。

损失厌恶：一个数，不是一个常数。前景理论里，结果被当作相对参照点的得或失，损失的那一支更陡，系数 λ 把损失一支和收益一支的斜率比出来。Brown、Imai、Vieider 与 Camerer（2024）的元分析收集了 150 篇文章里 1992—2017 年的 607 个 λ 估计：均值 1.955，95% 概率区间 [1.820, 2.102]；原始中位数 1.69；93.9% 的估计大于 1。按这个均值（线性价值函数、不考虑概率加权），一个一半机会输 100 元、一半机会赢一笔奖金的赌局，奖金要约 195.5 元才算打平。 A 但「λ ≈ 2」只是文献的中心；2.25 这个数来自 Tversky 与 Kahneman 1992 年的研究：25 名研究生，三个没有奖励的环节，取中位数（转引自 Brown 等人），比后来文献的均值 1.955 还高，也谈不上是一个常数。 D 「损失厌恶是普遍定律」也没站住：Gal 与 Rucker（2018）的综述认为证据整体上不支持损失比收益更有分量；Mrkva 等人（2020）用 5 个样本（N = 17,720）回应：领域知识和经验越多，损失厌恶越低，但各个水平的人都损失厌恶；Walasek 与 Stewart（2015）的四个实验里，只改变参与者看到的得失范围，就能得到损失厌恶、损失中性，甚至与损失厌恶相反的结果。所以站得住的是更窄的说法：在金钱的风险选择里，损失厌恶是一种会随情境而变的倾向，不是普遍定律。 B

三、「够用」凭什么可能是最优

现在回到论点。一个预测，总的平方误差可以拆成三项：偏差²＋方差＋噪声。偏差是模型平均下来的预测，和真实函数之间的系统性差距；方差是同一个模型从一个有限样本换到另一个样本时，会变动多少；噪声是谁也躲不掉的那部分。一个灵活的模型偏差小，但在观察少、噪声多的时候方差大——这就是偏差与方差的两难（Geman、Bienenstock 与 Doursat 1992；Gigerenzer 与 Brighton 2009 把它用在启发式上）。

Gigerenzer 与 Brighton（2009）的两个算例把这件事画得很清楚。其一：伦敦 2000 年的日均气温，对 30 个随机观测拟合多项式：次数越高，拟合已知数据的误差越低；预测新观测的误差却是 U 形的，最好的多项式次数是 4。其二：一个虚构的、恰好是 3 次多项式加噪声的温度规律，样本 30 个：3 次模型预测误差最低，但一个 2 次多项式（有偏差）比一个 10 次多项式（平均来说无偏）预测得更好——样本小的时候，一个有偏差的模型可以赢过无偏的。拟合不是预测。

真实数据上也能看到这个交叉。Czerlinski、Gigerenzer 与 Goldstein（1999）在 20 套真实数据上做了交叉验证（拿一部分数据去学，再用没学过的另一部分来打分；比如两所芝加哥中学哪所辍学率更高，线索有写作成绩、西语裔学生比例等）。四种规则里，「极简」是线索顺序随机的择优，「等权计数」（Dawes 的规则）是数哪边的线索多、不分轻重。Todd 与 Gigerenzer（2000）的表里，各规则的平均：

回归拟合得最好（77 对 75），预测得却不如择优（68 对 71）：这个交叉，就是过拟合的签名。但要读准幅度：heuristica 软件包的重算里，在 83 个德国城市的人口数据上（9 个二元线索，50/50 交叉验证，重复 200 次，书里是 10,000 次），拟合到预测：回归 75.2 → 70.8，择优 74.9 → 71.0，等权 73.6 → 70.2，极简 70.4 → 67.0——回归和择优只差 0.2 个百分点；在芝加哥辍学数据上，择优和等权的预测好过回归（只在图里）。所以「简单规则不输」成立，「碾压」不成立。 B 同类的结果还有：DeMiguel、Garlappi 与 Uppal（2009）在 7 个数据集上比较了 14 个投资组合模型，没有一个在夏普比率、确定性等价收益或换手率上稳定地好过「1/N」（平均分配）——按样本估计出最优权重的均值方差组合，要在美国股市里赢过 1/N，需要约 3,000 个月（25 个资产）到约 6,000 个月（50 个资产）的数据，约 250 年到 500 年，由两个数换算。但 Kirby 与 Ostdiek（2012）认为这结果很大程度来自研究设计，简单的主动择时策略能赢过 1/N。 B 这些是关于估计误差的研究结果，不是投资建议。

条件也要说明白：Gigerenzer 与 Brighton 的分析结果是，择优在「非补偿性」的环境里（线索的重要性悬殊到，排在前面的那个压得住后面的）是无偏的，启发式的优势取决于环境和样本量，所以「它避免了过拟合」只是个简称。下面这个部件，让你自己拨出这个条件。

四、动手：三种规则，谁在新案例上猜得更准

部件造一个小世界：6 个线索，彼此相关（相关系数 ρ），要预测的结果由这 6 个线索加权相加，再加噪声；噪声的大小，由「这个世界最多能被预测多少（R²）」定。三种规则从 n 个训练案例里学，然后预测 400 个新案例：回归（6 个线索，每个权重都从样本里估）、等权计数（只数线索，每个线索按它与结果的相关方向取正负号，权重相等，只拟合一个总的比例）、单线索（只用与结果相关最强的那一个，有「择优」的味道）。它们是这一类规则的替身，不是文献里的原模型；世界也是模拟的，不是人的数据。

拨几下，你会看到五件事。第一，默认设置下，等权计数一路领先：n = 20 时，回归 3.71、等权 3.20、单线索 3.81，噪声下限 2.96；回归要到 n 约 200 才几乎追平（3.02 对 3.00），而且没有超过。第二，看误差账：回归偏差几乎为零，吃亏全在方差（n = 20 时偏差² 0.04、方差 4.96）；单线索偏差大（偏差² 1.59）；等权计数故意偏一点（偏差² 0.17），换来稳很多（方差 1.34）。第三，点「多数据、干净的世界」（n = 200，R² = 0.9，权重较悬殊）：回归 0.57，等权 0.87，单线索 0.99，轮到认真算的占便宜。第四，点「一个线索压倒一切」（权重悬殊调到 0.9，其余不变）：n = 20 时三者几乎一样，单线索 1.49、等权 1.52、回归 1.55，只看一个线索的规则略占前列；差距小到换个随机种子，等权和单线索的名次就可能对调（回归落在最后倒是每次都一样）。第五，点「少数据、吵的世界」：n = 12，R² = 0.3 时，回归的误差（7.00）比等权（5.09）大三分之一以上。三个预设的赢家不一样：少数据、吵的世界里是等权计数，多数据、干净的世界里是回归，一个线索压倒一切时是单线索（差距很小）。谁赢，由 n、噪声和权重结构一起决定，没有哪一种规则在所有设置下都最准。

五、系统 1 与系统 2：一个比喻，不是两个器官

「系统 1 / 系统 2」这对词，常被归到 Stanovich 与 West（2000）名下，Kahneman 与 Frederick（2002）则用「属性替代」描述快的那一半：被问了一个难问题，却回答了一个容易的。Evans 与 Stanovich（2013）答复了五条批评，主张一个较弱的版本：快速、自主的 Type 1 过程给出默认的反应，除非被 Type 2 的推理干预；两类的区别，在于 Type 2 支持假设性思维、并重度占用工作记忆。

探这件事的一个测验是认知反思测验（CRT）。Frederick（2005）的三道题：球拍和球一共 1.10 美元，球拍比球贵 1 美元，球多少钱（直觉的 10 美分会让总数变成 1.20 美元，正确是 5 美分）；5 台机器 5 分钟做 5 个，100 台做 100 个要几分钟（5）；睡莲每天面积翻倍，48 天盖满湖面，盖住一半要几天（47）。Frederick 在 35 项研究里收集了 3,428 人：平均答对 1.24 题，答对 0、1、2、3 题的占 33%、28%、23%、17%；麻省理工学院的学生有 48% 全部答对，托莱多大学的学生只有 5%；答「10 美分」的人估计 92% 的人会答对，答「5 美分」的人估计 62%。Sinayev 与 Peters（2015）在 1,413 人的美国一般人群网络小组（Understanding America Study，按住址抽样招募）里：球拍与球一题，78% 给出直觉的错误答案（10 美分），14% 答对（5 美分）；睡莲一题，54% 犯直觉的错（24 天），29% 答对。 A 「直觉的错误很常见，而且在大而不同的样本里重复」是 A；怎么解释它，是另一回事。

批评直指解释。Melnikoff 与 Bargh（2018）概括了批评者的意见：常见的二分法（一类过程有意、可控、有意识、低效，另一类无意、不可控、无意识、高效）缺乏实证支持、与已确立的发现矛盾、内部也不自洽；两位作者自己的主张是，「现象分成两类」这个预设本身在阻碍进展。De Neys（2023）逐个检视快慢模型的两个特征：直觉和深思各自给出独有的反应（排他性），以及两者之间的切换机制；没有找到排他性的坚实依据，并认为切换的解释在概念上有问题，因为它们预设了排他性。数据也两头都有：Bago 与 De Neys（2019）用两次作答的范式（先在时间压力和负荷下答，再自由作答）做了七项研究，发现许多最终答对的人，在快速的第一次作答里就已经答对——正确的答案不一定是对直觉的「纠正」；Meyer 与 Frederick（2023）的 59 项新研究（N = 72,310，多为球拍与球一题）则发现，错误的直觉常常能顶住人们能被诱导的任何反思，尤其是当直觉近似正确的时候。直觉可以是对的，反思常常纠不了一个错的直觉。再如，把「字体难读」当作启动系统 2 的开关，在 Many Labs 2 里没有复制：原始 d = 0.63 [−0.004, 1.25]（41 人）→ 合并 d = −0.03 [−0.08, 0.01]（N = 6,935）。

研究小注
系统 1 / 系统 2 B D：「处理的快慢、费力程度和工作记忆负荷不同，这个对比对描述判断任务有用」是 B：受支持，但这些特征并不整齐地聚成两堆，「快等于错、慢等于对」也不是数据显示的。「心里有两个独立的系统，一个出错、一个纠错」作为字面的架构是 D（Evans 与 Stanovich 保留的是较弱的 Type 1 / Type 2 区分，即上一等级）。所以「系统 1 / 系统 2」是一个比喻，不是一个机制。

六、什么时候能信直觉，以及这套解释的边界

直觉的条件。Kahneman 与 Klein（2009）：要判断一个直觉可能有多好，要看环境有多可预测、此人有没有机会学到它的规律；主观的信心并不是准确度的可靠指标。「启发式与偏误」和「自然主义决策」两个阵营，在这条边界上是一致的。反过来读（本课的读法）：环境不可预测、或没有机会学到规律的地方，直觉的好坏就没有这个保证。这正是本课论点的另一面：捷径好不好，由环境决定。

「最优」的说法也要称。Lieder 等人（2018）的资源理性模型（在有限的时间预算下，从锚出发做调整）统一解释了十种锚定现象，包括准确性动机对「给定的锚」和「自己生成的锚」的不同影响；Lieder 与 Griffiths（2020）把「有限资源的理性使用」提为统一原则，论文在同一卷里引来 26 条公开评论。但一个能拟合已知现象的模型，还不是检验：Jones 与 Love（2011）、Bowers 与 Davis（2012）、Marcus 与 Davis（2013）从标题和摘要看，都批评理性或概率模型可以事后拟合、约束不足；Gould 与 Lewontin（1979）也提醒：一个性状今天有用，不等于它是为了这个用途被选出来的，一个合理的故事不是检验。 C 这一课没有说「所有的捷径都是最优的」；它说的是：是不是缺陷，要看环境和数据量，而且要一个一个称。

部件自己的边界。世界是线性的、线索是高斯的、噪声只有一种；三种规则是替身，不是文献里的原模型；曲线上的数是模拟的输出，不是人的数据，也不是 20 套真实数据的结果。n 小于线索数的区域（回归的方差会爆炸）没有画出来。

这一课的结果有多稳：明说的锚、问法的框架、损失比等量收益更重、CRT 上直觉的错误很常见，是 A；提取容易度、对死因的误判、「琳达」、忽视基率、简单规则不输、1/N、「快慢」作为一种对比、损失厌恶是一种随情境而变的倾向，是 B；幸运轮式的锚、「篮球里有很大的手感」、资源理性的解释，是 C；随手的无关数字做锚、一串词让人走得更慢、「没有手感」、λ = 2.25 是常数、字面的两个系统，是 D。

回到主线
引擎的第三个问题——为省力做了什么取舍（成本）——在这一课有了账：算力有限时，偏一点的简单规则因为稳，可以不输甚至更准；数据多、世界干净、权重悬殊时，认真算才占便宜；权重悬殊到一个线索压倒其余时，只看一个线索几乎就够。这和前面几课是同一件事：知觉在补全，注意在筛选，记忆在重建，都在拿旧经验换省力，而判断是这笔交易看得见的地方，也是不少说法被说过头的地方。第五条主线（证据）在这一课最忙：每个偏误都按今天的证据重新称过。下一课追问的是：有一类错误并不出在捷径上，而出在对「运气」的读法上——极端的结果下一次会自己往回走，而我们偏偏会为这种回走编一个因果故事。

常见误解

  • 误解：人的判断充满偏误，所以人是非理性的。 （澄清：「错」至少有四种读法（Stanovich 与 West）；满意化在不确定的世界里往往很有效（Artinger 等人 2022）。但也不能反过来说所有捷径都最优：是不是缺陷，要看环境和数据量。）
  • 误解：锚定就是说，随便一个数字都能左右你。 （澄清：明说的比较锚稳而大（A）；幸运轮式的随手数字没找到独立重复（C）；无关的数字：手机型号在 Many Labs 2 里 d = 0.04，社保号的重做也只剩「很弱」（D）。）
  • 误解：系统 1 出错，系统 2 纠错。 （澄清：CRT 的球拍与球一题，78% 给出直觉的错答案（A），但许多答对的人一开始就答对了，错误的直觉也常常顶住反思（Bago 与 De Neys 2019；Meyer 与 Frederick 2023）；字面的两个系统是 D，只是个比喻。）
  • 误解：手感是幻觉，篮球里没有热手。 （澄清：原来的分析用了有偏的估计量；校正之后，GVT 的受控实验差约 +12 到 +13 个百分点；「没有手感」是 D，「很大的手感」是 C，争论还在。）
  • 误解：简单规则总比复杂模型强。 （澄清：20 套数据平均只领先 3 个百分点，城市数据上是平手；在本课部件里，数据多、世界干净、权重悬殊时，回归就追上来了。）
  • 误解：损失的痛，是同样大小的收益的 2.25 倍。 （澄清：607 个估计的均值是 1.955，区间 [1.820, 2.102]；2.25 来自 25 名未加奖励的研究生；只改变得失的范围，就能让它消失甚至反转（Walasek 与 Stewart 2015）。）
一句话带走
「捷径」是缺陷还是最优，取决于环境和数据量，不取决于有没有走捷径：数据少、世界吵、线索差不多重要时，偏一点的简单规则因为稳，可以不输，有时甚至更准（B）；在本课的模拟里，数据多、世界干净、权重悬殊时，认真算才占便宜，而权重悬殊到一个线索压倒其余、数据又少时，只看这一个线索几乎就够。具体的偏误要一个一个称：明说的锚、问法的框架、CRT 上直觉的错误，大而稳（A）；随手的数字、一串词的行为启动、「没有手感」，被夸大或没站住（D、C）。
