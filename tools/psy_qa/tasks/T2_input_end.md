Read `tools/psy_qa/briefs/RESEARCH.md` first. Lessons covered: **03** perception, **04** attention, **05** memory.
Story: perception = inference with priors (priors are *learned*, so they can differ and shift); attention = the
bandwidth gate; memory = compressed, reconstructed, and (importantly) *rational* given the statistics of the world.
