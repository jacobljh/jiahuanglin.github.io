Read `tools/psy_qa/briefs/RESEARCH.md` first. Lessons covered: **07** value & emotion (the body's ledger), **08** where the
model is written (neurons, synapses, plasticity), **09** learning (only surprise teaches).
Story: a mind that must keep a body alive needs a *value* signal (homeostasis → affect); emotions are how the brain
categorises that signal in context (and this is CONTESTED: basic-emotion vs constructed-emotion views — present both);
learning updates the model in proportion to surprise; the model is physically the synaptic weights.
